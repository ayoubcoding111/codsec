Project Details · Full-Stack Ordering Platform

Customers browse, customize and track orders live. Staff run a live kitchen feed. Admins manage menu, staff, zones and analytics — in English, French and Arabic (RTL). No frameworks, no build step.

LanguagesEN / FR / AR + RTL
01 · Ordering & Cart

Customizable menu, fly-to-cart, Algerian checkout

Category filters + real-time search. Click any dish to add extra ingredients (multi-pick) or drink sizes 30cl / 1L / 2L (single-pick) with live total — names in EN/FR/AR. Cart persists in localStorage, combos with different options stay on separate lines.

  • Algerian phone validation (05/06/07 or +213), frontend + backend
  • Confirmation page + order number deep-linking to tracking
  • Rate-limited public endpoints, dark / light theme
Landing — hero, hours, contact
02 · Live Tracking

Track by order number + phone, privacy-first

#track timeline — pending → confirmed → preparing → ready → on the way → delivered — auto-refresh every 30s, pauses when tab hidden, pre-filled from your last order.

  • Both id + phone required, masked PII, no-store
  • Same generic “not found” — orders can’t be enumerated
  • Delivery zones with fee, free-over threshold, ETA
Cart — quantities, zones, checkout
03 · Kitchen & Admin

Live kitchen feed + full admin portal

Staff see status badges + filters + one-click status flow, 15s refresh with chime + flashing NEW highlight, optional browser notifications, click-to-copy phone. Admins manage staff, menu (photo + priced EN/FR/AR options), zones, reviews and analytics.

  • Analytics: revenue cards, 7/14/30-day deltas, SVG charts, CSV export
  • Delivered orders purge after 24h into delivery_stats — PII gone, revenue kept
  • Zero admin code ships on the public page
Admin — analytics, charts, export
04 · Security & Polish

Hardened auth, trilingual RTL, zero-build frontend

RBAC (admin/staff), httpOnly cookie + Bearer fallback, bcrypt, login with username or email. Brute-force defense: IP rate limits + 5 fails → 15min lockout + 20 fails → 60min IP ban persisted across restarts. Password reset via Nodemailer (1h token).

  • Generic responses everywhere — no account/oracle leaks
  • EN / FR / AR globe menu, full RTL, SVG icons, scroll-reveal
  • Auto-migrations on boot, seed-safe restarts, env-tunable limits
Menu — filters, search, customization

🍕 Delicious Restaurant — snapshot (offline fallback)

Full-stack food ordering + delivery. Live tracking by order number + phone, kitchen dashboard with alerts, /admin portal with analytics, staff/menu/zones management, email login + password reset, EN/FR/AR RTL. Brute-force resistant auth, delivered orders auto-purge after 24h (counts + revenue kept).

  • Highlights: separated public/admin surfaces, layered auth defense, privacy-by-design tracking, zero-build frontend, operable backend (auto-migrations).
