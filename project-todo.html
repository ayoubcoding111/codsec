01 · Kanban Board

Drag-and-drop across 4 columns

Native HTML5 drag-and-drop with column highlighting, card animations and task counts. Move tasks freely between any columns — status syncs instantly to MySQL with optimistic rendering.

  • Color-coded statuses, visual feedback on every move
  • CRUD + descriptions + timestamps, friendly error states
  • RESTful MVC — no build step for the frontend
User board — 4 columns, counts, drag-drop
02 · Auth & Experience

Secure login, dark mode that remembers you

JWT sessions, bcrypt (10 rounds), role-based middleware, parameterized SQL, CORS + env secrets. CSS-variable theming with localStorage persistence, Fraunces + Inter type, staggered fade/slide/scale animations.

  • Login / register tabs, protected routes, admin-only endpoints
  • Responsive desktop → tablet → mobile
  • Hover, drag and active states on every interaction
Login — dark mode + tab navigation
03 · Admin Oversight

Every user’s board, one clean view

Admin dashboard lists all users, drills into any user’s complete Kanban board, with real-time user + task metrics and status breakdowns.

  • GET /api/admin/users, per-user todos, delete user, all todos
  • PATCH /api/todos/:id/status for drag-drop sync
  • Modular controllers / routes / middleware, ESLint-ready
Admin — users, stats, per-user boards
